## 📖 Overview

**ZenFocus** is a web-based productivity tool designed to help students and professionals eliminate distractions. It integrates the **Pomodoro Technique** with a high-quality **Ambient Audio Engine**, allowing users to mask distracting noises and enter a state of flow.

The project features a sleek, "Glassmorphism" UI built with **Tailwind CSS**, fully optimized for performance with a custom-built TypeScript audio engine that handles seamless looping and volume mixing without server latency.

## ✨ Key Features

* **🍅 Smart Pomodoro Timer:** Fully customizable timer for Focus sessions, Short Breaks, and Long Breaks.
* **🎧 Immersive Ambience:** High-quality, loopable soundscapes including **Rainfall, Ocean Waves, Lo-Fi Beats, and White Noise**.
* **🎛️ Audio Mixing:** Independent volume controls for each sound track, allowing users to create their perfect background mix (e.g., Rain + Lo-Fi).
* **🎨 Modern Aesthetics:** A clean, futuristic interface featuring glassmorphism effects, smooth animations, and a responsive layout.
* **⚡ Zero Latency:** Powered by a custom `AudioEngine.ts` class, ensuring sounds play instantly from the client-side without buffering.
* **🔋 Efficiency:** Lightweight architecture that runs entirely in the browser.

## 🛠️ Tech Stack

* **Core:** React 18, TypeScript (Strict Mode)
* **Build Tool:** Vite
* **Styling:** Tailwind CSS (Custom animations & Glassmorphism)
* **Audio:** Native HTML5 Audio API (Custom AudioEngine Class)
* **Icons:** Lucide React

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites
* Node.js (v16 or higher)
* npm

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/willbyers1/ZenFocus.git](https://github.com/willbyers1/zenfocus.git)
    cd zenfocus
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  Open your browser and navigate to `http://localhost:5173`.

## 🎮 Usage

1.  **Set Your Goal:** Choose a focus duration (default is 25 minutes) or select a break mode.
2.  **Mix Your Sound:** Toggle the ambient sounds (Rain, Wind, Lo-Fi) on/off.
3.  **Adjust Volume:** Use the sliders to blend the sounds to your liking (e.g., low thunder with loud rain).
4.  **Start:** Click the Play button to start the timer and enter the zone.
5.  **Focus:** The audio will loop seamlessly until your session is complete.
